# 무황기협전 4대 버전 비교 쇼케이스 (미스터블루 제안용)

## 프로젝트 개요
본 저장소는 '무황기협전 [개정판] 제1권'의 출판만화 AI 파이프라인 4대 버전 진화 로드맵을 미스터블루에 제안하기 위한 100% 정적 웹 쇼케이스 패키지입니다.

### 4대 버전 구성
1. **V1. 원작 컬러판 (112쪽 전권 대조)**: 원작 흑백 vs 뷰어(comic_view.asp?id=73) 정본 컬러 1:1 대조 인터랙티브 뷰어 (1~112쪽 완편)
2. **V2. 캐릭터시트 적용 (6인 실물)**: 당사 566개 아카이브 중 핵심 주연 6인(군악, 청풍, 상관옥, 단우성, 설하, 묵검호) 실물 2048x1536 컬러/먹선 정본 시트 뷰어
3. **V3. AI 시네마틱 연출**: 1~14쪽 장엄한 산세, 한시 해설 등 영화적 구도의 본제품 인트로 뷰어
4. **V4. 정통 무협 흑백판**: 105쪽 묵직한 펜선, 깊은 먹 명암, 스크린톤을 살린 무협 정통 흑백 에디션
